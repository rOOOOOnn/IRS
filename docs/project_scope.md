# Project Scope

## Phase 1 — Included

- Repository and cross-platform environment setup.
- Bloomberg Excel inspection and provenance.
- Data standardization without silent imputation.
- Missingness, duplicate, coverage, and outlier reporting.
- Chronological split assignment and observation counts.
- Team responsibilities, data contracts, and collaboration guidance.
- Synthetic test fixtures and basic unit tests.

## Phase 1 — Excluded

- Yield-curve bootstrapping, interpolation, and calibration.
- IRS cash-flow generation, pricing, and daily MTM.
- Historical Simulation, EWMA, PCA-MC, VaR, and ES.
- Ensemble or decision-tree weighting.
- Backtesting implementation.

Excluded modules contain only future interface notes so placeholders cannot be mistaken for working models.
