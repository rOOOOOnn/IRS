# Project Timeline

## Phase 1 — Project and Data Foundation

- Confirm source definitions and units.
- Run inspection, preprocessing, validation, and split reports.
- Approve interfaces and team ownership.
- Resolve repository data-licensing exposure.

## Phase 2 — Curve and Pricing

- Implement curve instruments and conventions.
- Bootstrap and interpolate daily curves.
- Validate discount factors and zero rates.
- Implement IRS cash flows, daily MTM, and P&L.

## Phase 3 — Risk and Ensemble

- Implement HS, EWMA, and PCA-MC.
- Produce standardized VaR and ES forecasts.
- Design validation-only ensemble selection and dynamic weights.

## Phase 4 — Backtesting and Evaluation

- Run final out-of-sample VaR and ES backtests.
- Compare individual and ensemble models.
- Prepare visualizations, report, and presentation.
